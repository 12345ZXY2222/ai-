# Scripts

This folder contains the one-off / research / utility Python scripts that were previously in the repo root.

## Folders

- `analysis/`: analysis scripts (metrics, comparisons, market/bullwhip analysis)
- `experiments/`: experiment runners & reproduction scripts (`run_*`, `reproduce_*`, setup helpers)
- `pdf/`: PDF parsing, reference extraction, prompt extraction tools
- `plots/`: plotting / image composition utilities
- `debug/`: debugging helpers, environment checks, fix utilities
- `tests/`: ad-hoc test scripts (not the backend unit tests)

## Notes

Most scripts assume you run them from the repo root:

```bash
cd "ai模拟平台（12.17）"
python scripts/<category>/<script>.py
```
